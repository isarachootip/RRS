# คู่มือการใช้งานสำหรับฝ่ายบัญชีและการเงิน (Accounting Manual)

คู่มือฉบับนี้สำหรับผู้ใช้งานบทบาท **ฝ่ายบัญชี (`ACCOUNTING`)** สำหรับจัดการรายรับ-รายจ่ายห้องของบริษัท (`OWNER`) การอนุมัติค่านายหน้า การรับเงินจากเจ้าของห้อง การจ่ายส่วนแบ่งให้ Agent และการออกรายงานการเงิน

---

## 1. การเข้าสู่ระบบด้วย 2FA

บัญชีบทบาท `ACCOUNTING` ทุกบัญชีบังคับเปิดใช้งาน **การยืนยันตัวตนสองขั้นตอน (2FA)** เพื่อความปลอดภัยของข้อมูลการเงินและการอนุมัติจ่ายเงิน

---

## 2. การจัดการค่าเช่ารายเดือนและค่าใช้จ่ายห้องบริษัท (`/finance`)

ไปที่เมนู **การเงินห้อง Owner (`/finance`)**:

1. **ตารางงวดค่าเช่ารายเดือน (`Rent Schedules`)**:
   - เมื่อสัญญาเช่าห้องประเภท `OWNER` มีสถานะ `ACTIVE` ระบบจะสร้างงวดค่าเช่ารายเดือนให้อัตโนมัติ
   - กดปุ่ม **บันทึกรับชำระเงิน** เลือกวิธีชำระ (โอนเงิน, พร้อมเพย์, เงินสด) และแนบไฟล์สลิปหลักฐาน ระบบจะตัดยอดสถานะงวดจาก `DUE` → `PARTIAL` → `PAID` อัตโนมัติ
2. **บันทึกค่าใช้จ่าย (`Expenses`)**:
   - กดปุ่ม **บันทึกค่าใช้จ่าย** เลือกห้อง หมวดค่าใช้จ่าย (`ค่าส่วนกลาง`, `ค่าซ่อมแซม`, `ค่าน้ำ/ไฟ`, `ภาษี`, `ทำความสะอาด`) ระบุจำนวนเงินและแนบใบเสร็จ
3. **รายงานรายได้สุทธิห้อง Owner (`Owner Net Income`)**:
   - ตรวจสอบรายรับจริงหักค่าใช้จ่ายและค่านายหน้าตามเกณฑ์เงินสด (`Cash Basis`) แยกรายห้องและรายเดือน

---

## 3. การตรวจสอบ อนุมัติ และปรับปรุงค่านายหน้า (`/commissions`)

ไปที่เมนู **ค่านายหน้า (`/commissions`)**:

1. **ตรวจสอบและอนุมัติ**:
   - ตรวจสอบสูตรค่านายหน้า (`1 เดือน`, `% ค่าเช่ารวม`, `N เดือน`, `เหมาจ่าย`, `% ราคาขาย`) และตารางส่วนแบ่งของแต่ละบทบาท รวมถึงภาษีหัก ณ ที่จ่าย 3% สำหรับ Agent ฟรีแลนซ์
   - กดปุ่ม **อนุมัติค่านายหน้า** ระบบจะบันทึก Snapshot ลงตาราง `commission_revisions` ทันที:
     - หากเป็นห้อง `AGENT`: สถานะเปลี่ยนเป็น `APPROVED` / `AWAITING_OWNER_PAYMENT`
     - หากเป็นห้อง `OWNER`: ข้ามขั้นตอนรับเงินจากเจ้าของห้องไปเป็น `AWAITING_PAYOUT` ทันที
2. **การแก้ไขหลังอนุมัติ (Revision)**:
   - หากมีการเปลี่ยนแปลงข้อตกลงหรือผู้เช่าออกก่อนกำหนด ต้องระบุ **เหตุผลในการปรับปรุง** ระบบจะสร้าง `Revision` ใหม่ (`revision + 1`) โดยเก็บประวัติฉบับเดิมไว้ครบถ้วน

---

## 4. การบันทึกรับเงินจากเจ้าของห้องและจ่ายส่วนแบ่ง Agent (`/commissions`)

1. **รับเงินค่านายหน้าจากเจ้าของห้อง**: กดปุ่ม **บันทึกรับเงินเจ้าของ** ระบุยอดเงิน วันที่รับ และแนบหลักฐานการโอน
2. **สร้างรอบจ่ายเงินให้ Agent (`Batch Payout`)**:
   - เลือก Agent ระบุชื่อรอบจ่าย (เช่น `รอบพฤษภาคม 2026`) เลือกรายการส่วนแบ่งที่ต้องการรวมจ่าย แล้วกดยืนยันการโอนจ่ายพร้อมแนบสลิป

---

## 5. การออกรายงานสรุปและส่งออกไฟล์ (`/reports`)

ไปที่เมนู **รายงาน (`/reports`)** เลือกช่วงวันที่และมิติการจัดกลุ่ม (`รายเดือน/ปี`, `Owner vs Agent`, `โครงการ`, `Agent รายบุคคล`, `รายสัญญา/ดีล`) แล้วกด **Export CSV** หรือ **Export Excel (.xlsx)** เพื่อนำไปใช้ทางบัญชีได้ทันที
