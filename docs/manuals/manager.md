# คู่มือการใช้งานสำหรับผู้จัดการทีม (Manager Manual)

คู่มือฉบับนี้สำหรับผู้ใช้งานบทบาท **ผู้จัดการทีม (`MANAGER`)** สำหรับกำกับดูแลทีม โอนผู้รับผิดชอบลูกค้า อนุมัติประกาศ และติดตามผลงานของทีม

---

## 1. ขอบเขตการมองเห็นและสิทธิ์ของ Manager

- **สินทรัพย์และเจ้าของทรัพย์**: ดูได้ทั้งหมดทั้งบริษัท (`ALL`) และดูราคาต่ำสุดที่อนุมัติให้เสนอได้ (`minRentPrice` / `minSalePrice`) แต่แก้ไขสินทรัพย์ได้เฉพาะของทีมตัวเอง (`D15`)
- **ลูกค้า นัดหมาย การจอง สัญญา และรายงาน**: ดูและจัดการข้อมูลของสมาชิกทุกคนในทีมตัวเอง (`TEAM`)

---

## 2. การมอบหมายและโอนผู้ดูแลลูกค้า (`/leads`)

1. ไปที่เมนู **ลูกค้า (`/leads`)** เพื่อดูรายการลูกค้าของทีมในรูปแบบตารางหรือกระดาน **Kanban**
2. คลิกเปิดรายละเอียดลูกค้าที่ต้องการโอนผู้ดูแล
3. ในส่วน **การโอนผู้ดูแล (Lead Assignment)** เลือก Agent คนใหม่ในทีมและระบุเหตุผลการโอน (เช่น เกลี่ยงาน หรือผู้ดูแลเดิมลาพักร้อน)
4. ระบบจะบันทึกประวัติการโอนลง `lead_assignments` พร้อมส่งแจ้งเตือนหาผู้ดูแลเดิมและผู้ดูแลใหม่ทันที

---

## 3. การอนุมัติผู้ร่วมงานในดีล (Collaborators) และตรวจคำขอร่วมงาน

1. เมื่อ Agent พบข้อมูลลูกค้าซ้ำและกด **ขอร่วมงาน** ระบบจะแสดงรายการคำขอในรายละเอียดของลูกค้านั้น
2. ผู้จัดการทีมหรือเจ้าของหลักของลูกค้าสามารถกด **อนุมัติ (`APPROVED`)** หรือ **ปฏิเสธ (`REJECTED`)** พร้อมกำหนดบทบาทในดีล (`FINDER`, `SHOWING`, `CLOSER`)

---

## 4. การตรวจสอบตารางนัดหมายทีมและติดตามงานค้าง (`/appointments`)

1. เปิดเมนู **นัดดูห้อง (`/appointments`)** เลือกมุมมอง **วัน / สัปดาห์ / เดือน** และกรองตามสมาชิกในทีม
2. เมื่อมีลูกค้าที่ไม่มีกิจกรรมติดต่อกันเกิน 30 วัน หรือเลยกำหนดวันติดตาม (`nextFollowUpAt`) ระบบจะส่งแจ้งเตือน Escalation มายังผู้จัดการทีมโดยอัตโนมัติ

---

## 5. การเสนอสัดส่วนค่านายหน้าและดูรายงานทีม (`/commissions`, `/`, `/reports`)

1. ในหน้า **ค่านายหน้า (`/commissions`)** ผู้จัดการทีมสามารถตรวจสอบสูตรคำนวณ ใช้เทมเพลต **30 / 20 / 30 / 20** เพื่อเติมชื่อ Agent ตามบทบาทอัตโนมัติ และบันทึกสัดส่วนส่งให้ฝ่ายบัญชีอนุมัติ
2. ในหน้า **ภาพรวม (`/`)** และ **รายงาน (`/reports`)** สามารถกรองดู KPI อัตราการปิดดีล (`Funnel`) และส่งออกรายงาน (`Export CSV / Excel`) ของทีมได้ทันที
