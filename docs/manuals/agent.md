# คู่มือการใช้งานสำหรับเอเจนต์ (Agent Manual)

คู่มือฉบับนี้สำหรับผู้ใช้งานบทบาท **เอเจนต์ (`AGENT`)** สำหรับดูแลเจ้าของทรัพย์ สินทรัพย์ ลูกค้า การจับคู่ห้อง นัดดูห้อง การจอง และการทำสัญญา

---

## 1. การบันทึกเจ้าของทรัพย์และสินทรัพย์ (`/owners`, `/assets`)

1. ไปที่เมนู **เจ้าของทรัพย์ (`/owners`)** กด **เพิ่มเจ้าของทรัพย์** กรอกชื่อ เบอร์โทรศัพท์ และ LINE ID (หากเบอร์ซ้ำ ระบบจะแจ้งเตือนก่อนบันทึก)
2. ไปที่เมนู **ทรัพย์สิน (`/assets`)** กด **เพิ่มทรัพย์สิน** เลือกประเภทสินทรัพย์ (เช่น คอนโด บ้าน ทาวน์โฮม ที่ดิน โกดัง) และระบุประเภทการดูแล (`AGENT` = รับฝากจากเจ้าของ, `OWNER` = ห้องของบริษัท)
3. อัปโหลดรูปภาพห้อง จัดเรียงลำดับรูป ตั้งค่ารูปปก และบันทึกสัญญาฝากเช่า/ฝากขาย (`Listing Agreement`)

---

## 2. การรับลูกค้าใหม่และตรวจสอบลูกค้าซ้ำ (`/leads`)

1. ไปที่เมนู **ลูกค้า (`/leads`)** กด **เพิ่มลูกค้าใหม่**
2. ขณะกรอกเบอร์โทรศัพท์ LINE หรืออีเมล ระบบจะตรวจสอบข้อมูลซ้ำอัตโนมัติ:
   - หากมีเอเจนต์ท่านอื่นดูแลอยู่แล้ว ระบบจะแสดงชื่อย่อและชื่อผู้ดูแลหลัก (โดยปกปิดเบอร์โทรเต็มเป็น `08x-xxx-xxxx`) พร้อมปุ่ม **ขอร่วมงาน** เพื่อป้องกันการแย่งลูกค้า
3. บันทึกความต้องการของลูกค้า (งบประมาณ ทำเล ประเภทห้อง วันเข้าอยู่ เลี้ยงสัตว์)

---

## 3. การจับคู่ห้องอัตโนมัติและส่งลิงก์ให้ลูกค้า (`/leads/[id]`)

1. ในหน้ารายละเอียดลูกค้า กดแท็บ **จับคู่ห้อง (Matching)** ระบบจะคัดเฉพาะห้องว่าง (`AVAILABLE`) ที่ตรงเงื่อนไขและเรียงตามคะแนนความเหมาะสม (`matchScore`)
2. เลือกห้องที่ต้องการเสนอแล้วกด **สร้างลิงก์แชร์ให้ลูกค้า**
3. คัดลอกลิงก์ `/share/[token]` (มีอายุ 7 วัน) ส่งให้ลูกค้าทาง LINE ได้ทันที โดยหน้าแชร์จะไม่แสดงราคาต่ำสุด เลขห้อง หรือข้อมูลติดต่อเจ้าของทรัพย์

---

## 4. การนัดดูห้อง บันทึกผลติดตาม จอง และทำสัญญา (`/appointments`, `/bookings`, `/contracts`)

1. **นัดดูห้อง (`/appointments`)**: เลือกลูกค้า วัน-เวลา และเลือกห้องที่จะพาดูได้หลายห้องในนัดเดียว (หากชนเวลานัดอื่นของตนเอง ระบบจะแจ้งเตือนให้ยืนยัน)
2. **บันทึกผลติดตาม**: หลังพาดูห้องเสร็จ กดเปลี่ยนสถานะนัดเป็น **นัดสำเร็จ (`COMPLETED`)** ระบบจะบังคับบันทึกผลรายห้อง (`ชอบ`, `ต่อรองราคา`, `ตกลงเช่า`, ฯลฯ) และระบุวันติดตามครั้งถัดไป
3. **ใบจอง (`/bookings`)**: เมื่อลูกค้าตกลงจอง สร้างใบจองระบุช่วงสัญญาและบันทึกชำระเงินจอง ระบบจะล็อกห้องในช่วงวันดังกล่าวทันที
4. **สัญญาเช่า (`/contracts`)**: แปลงใบจองเป็นสัญญาเช่า (`LS-YYYY-NNNN`) และกดยืนยันการลงนาม ระบบจะเปลี่ยนสถานะห้องเป็น `CONTRACTED` และสร้างรายการค่านายหน้าให้อัตโนมัติ

---

## 5. การผูกบัญชี LINE และดูส่วนแบ่งค่านายหน้าของตนเอง (`/notifications`, `/commissions`)

- ไปที่ **การแจ้งเตือน (`/notifications`)** เพื่อผูก `LINE User ID` และเลือกช่องทางรับแจ้งเตือนรายเหตุการณ์
- ไปที่ **ค่านายหน้า (`/commissions`)** เพื่อดูสถานะและยอดส่วนแบ่งค่านายหน้าเฉพาะรายการของตนเอง
