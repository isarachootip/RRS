# ลำดับการรัน prompt เพื่อสร้างระบบ RRS

ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ `prompts` ของโปรเจกต์ (ถ้าโค้ดอยู่คนละที่ ให้คัดลอกโฟลเดอร์นี้ไปไว้ที่ `<โฟลเดอร์โปรเจกต์>\prompts\`)

## ก่อนเริ่มทุกครั้ง
1. เปิด Docker Desktop
2. PowerShell: `cd <โฟลเดอร์โปรเจกต์>` → `git checkout main` → `git pull` → `docker compose up -d`
3. พิมพ์ `claude` เพื่อเปิด Claude Code
4. วางเนื้อหา `00-CONTINUE.md` เป็นข้อความแรกของทุก session

Phase 7 เริ่มได้หลัง Phase 3 เสร็จ ถ้าอยากเปิดเว็บสาธารณะเร็วขึ้น

## ในแต่ละ Phase
1. กรอก `[ใส่...]` ในไฟล์ Phase ก่อนวาง (คำถามกฎธุรกิจ)
2. วาง prompt ของ Phase → AI เสนอแผนงานย่อยแรก → ตรวจ → พิมพ์ `ทำเลย`
3. AI ทำเสร็จ push branch → เปิด Pull Request บน GitHub
4. เปิด session ใหม่ วาง `tasks/R1.md` (ใส่เลขงาน) ให้รีวิว → แก้ตามรีวิว → merge
5. กลับ session เดิมพิมพ์ `งานถัดไปในเฟสนี้` จนครบทุกงานย่อย
6. ลองสถานการณ์ "สาธิตเมื่อจบเฟส" ท้ายไฟล์ Phase ด้วยตัวเอง ผ่านครบแล้วจึงไป Phase ถัดไป
